 1. 프로젝트 개요
이 프로젝트에서는 터미널에서 메뉴 번호를 입력하여 프롬프트를 관리하는 Python 프로그램을 제작하였습니다. 프롬프트 추가, 전체 목록 보기, 카테고리별 보기, 검색, 상세 보기, 즐겨찾기 추가·해제와 즐겨찾기 목록 보기 기능을 사용할 수 있습니다.
필수 기능은 따로 설치해야 하는 프로그램 없이 Python 기본 문법만 사용하여 구현하였습니다. 프롬프트는 리스트와 딕셔너리에 저장하였으며, 각 프롬프트에는 제목, 내용, 카테고리, 즐겨찾기 여부가 들어 있습니다. 보너스 기능으로 JSON 저장·불러오기와 카테고리별 Markdown 내보내기를 추가하였습니다. 따라서 프로그램을 종료한 후 다시 실행해도 추가한 내용과 즐겨찾기 상태가 유지됩니다.

최종 결과  필수 기능 전체, GitHub 업로드, 14개 커밋, 브랜치 병합, JSON 저장·불러오기, Markdown 내보내기를 모두 완료하였습니다.

 5. 필수 기능 구현 및 실행 결과
 5.1 메뉴 선택과 프로그램 실행
프로그램을 실행하면 1번부터 8번까지의 기능 메뉴와 0번 종료 메뉴가 표시됩니다. 사용자가 번호를 입력하면 해당 기능이 실행되며, 작업이 끝나면 다시 메인 메뉴로 돌아옵니다. 잘못된 번호를 입력하면 안내 문장이 표시되고 메뉴가 다시 나타납니다.


그림 3. 번호 입력 방식의 메인 메뉴 실행 화면
주석  프로그램을 실행하면 1번부터 8번까지의 기능과 0번 종료 메뉴가 표시됩니다. 사용자는 원하는 번호를 입력하여 기능을 선택할 수 있습니다.

 5.2 프롬프트 추가 및 목록 보기
제목, 내용, 카테고리를 입력하면 새 프롬프트가 등록됩니다. 아무것도 입력하지 않으면 다시 입력하라는 안내가 표시됩니다. 새 프롬프트는 처음에는 즐겨찾기하지 않은 상태(False)로 저장됩니다. 목록 화면에는 번호, 카테고리, 제목과 즐겨찾기 별표가 함께 표시됩니다.


그림 4. 새 프롬프트가 전체 목록에 반영된 결과
주석  ‘블로그 제목 생성’ 프롬프트를 추가한 뒤 전체 목록을 확인한 화면입니다. 새 프롬프트가 5번으로 등록되었으며, 전체 개수도 5개로 늘어났습니다.

 5.3 카테고리별 조회
카테고리 목록에서 번호를 선택하면 해당 카테고리의 프롬프트만 모아서 보여줍니다. 텍스트 생성 카테고리를 선택한 결과, 해당 프롬프트 3개가 표시되었습니다.


그림 5. 텍스트 생성 카테고리별 조회 결과
주석  텍스트 생성 카테고리를 선택한 화면입니다. 해당 카테고리에 들어 있는 프롬프트 3개만 표시되어 카테고리별 조회 기능이 정상적으로 작동하는 것을 확인하였습니다.

 5.4 프롬프트 검색
영어 검색어는 대문자와 소문자를 따로 구분하지 않도록 모두 소문자로 바꾼 뒤 찾습니다. 입력한 말이 프롬프트의 제목이나 내용에 들어 있으면 검색 결과에 표시됩니다. ‘블로그’를 검색한 결과, 프롬프트 2개가 검색되었습니다.


그림 6. 제목 또는 내용 기준 키워드 검색 결과
주석  검색어로 ‘블로그’를 입력한 화면입니다. 제목이나 내용에 ‘블로그’가 들어 있는 프롬프트 2개가 검색되었습니다.

 5.5 프롬프트 상세 보기
프롬프트 번호를 입력하면 제목, 카테고리, 즐겨찾기 여부와 내용 전체가 구분선과 함께 표시됩니다. 글자를 입력하거나 목록에 없는 번호를 입력하면 잘못된 입력이라는 안내가 표시된 뒤 메뉴로 돌아갑니다.


그림 7. 블로그 제목 생성 프롬프트의 상세 보기
주석  5번 프롬프트의 상세 내용을 확인한 화면입니다. 제목, 카테고리, 즐겨찾기 여부와 전체 내용이 함께 표시되었습니다.

 5.6 즐겨찾기 관리
즐겨찾기를 선택하면 favorite 값이 False에서 True로 바뀝니다. False는 즐겨찾기하지 않은 상태이고, True는 즐겨찾기한 상태를 뜻합니다. 즐겨찾기 목록에서는 True인 프롬프트만 별표와 함께 표시됩니다.


그림 8. 즐겨찾기 프롬프트만 모아서 출력한 결과
주석  즐겨찾기로 선택한 프롬프트 2개가 별표와 함께 표시된 화면입니다. 즐겨찾기에 추가한 프롬프트만 모아서 확인할 수 있습니다.

 6. 보너스 기능 구현
 6.1 JSON 저장 및 불러오기
Python에 기본으로 들어 있는 json 기능을 사용하여 프롬프트를 prompts.json 파일에 저장하였습니다. 프로그램을 시작하면 load_prompts() 함수가 저장된 내용을 읽습니다. 파일이 없으면 기본 프롬프트가 들어 있는 새 파일을 만듭니다. 프롬프트를 추가하거나 즐겨찾기를 변경하면 save_prompts() 함수가 바뀐 내용을 바로 저장합니다.
· 	프로그램 종료 후 재실행해도 추가한 프롬프트가 유지됨
· 	프로그램 종료 후 재실행해도 즐겨찾기 상태가 유지됨
· 	UTF-8과 ensure_ascii=False를 사용하여 한글이 깨지지 않게 저장함
· 	indent 값을 사용하여 JSON 파일을 줄마다 보기 쉽게 정리함
 6.2 카테고리별 Markdown 내보내기
Python의 Path 기능을 사용하여 exports 폴더를 만들었습니다. 프롬프트를 카테고리별로 나눈 뒤 카테고리 이름으로 Markdown 파일을 만들었습니다. 각 파일에는 프롬프트 제목, 즐겨찾기 별표와 내용 전체가 기록됩니다.


그림 9. exports 폴더와 카테고리별 Markdown 파일 생성 결과
주석  8번 메뉴를 실행하여 exports 폴더를 만든 화면입니다. 폴더 안에 이미지 생성, 자동화, 텍스트 생성으로 나눈 Markdown 파일 3개가 생성되었습니다.
